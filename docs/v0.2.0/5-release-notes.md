# 版本发布说明：AI 权限控制与审计闭环 (v0.2.0)

我们已成功完成了 `bagujing` AI 服务安全与可观测层面的重大升级，建立了从底层配额到上层审计的全链路防护体系。

## 新功能
- **深度 AI 安全防护**：
    - **角色级限额**：支持按用户角色（如 `admin`、`user`）设置默认 Token 消耗限额。
    - **用户自定义配额**：管理员可为特定高价值或受限用户设置专属额度，优先级高于角色默认配置。
    - **全局兜底策略**：在未配置具体额度时，自动回退到系统全局硬边界，确保成本不失控。
- **持久化审计追踪**：
    - 所有 AI 请求均实时写入 SQLite 数据库 (`ai_audit_logs`)。
    - 记录信息包括：用户标识、Token 使用量、处理耗时、决策原因及原始请求摘要。
- **RAG 上下文增强**：
    - 在题目生成解析时，自动关联分类背景、分组描述及核心考点。
    - 优化了提示词工程，确保 AI 以“资深面试官”身份输出结构化的 HTML 答案。
- **用户管理与权限集成**：
    - 集成了现有的用户中心，实现了基于 JWT 令牌的 AI 访问授权。
    - 增加了注册审批流，确保核心模型资源仅对活跃授权用户开放。

## 性能与稳定性优化
- **智能语义缓存**：
    - 对高频出现的题目解析请求进行 Hash 缓存，有效期 24 小时。
    - 有效降低了重复调用的 Token 支出并显著提升了响应速度。
- **自动资源回收**：
    - 引入了 SSE (Server-Sent Events) 空闲计时器，自动断开无响应的流式连接，防止后端计算资源堆积。
- **混合部署支持**：
    - 全面适配 PM2 生产环境，集成了 HTTPS 证书管理及静态服务器反向代理逻辑。

## 修复路径
- 修复了非安全上下文下 `crypto.subtle` 前端签名库报错的问题。
- 解决了移动端题目列表过滤器重叠导致的点击失效 UI 问题。
- 优化了后端异常处理逻辑，针对上游 API 超时或网络抖动增加了健壮性捕获。
